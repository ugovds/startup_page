# Violet Startpage

An aesthetic startpage theme featuring a violet palette, customizable links, search bar, and widgets.

## Preview & Usage

Simply open `index.html` in your favorite web browser or configure it as your browser's new tab / homepage.

### Customization

- Edit `index.html` to configure links, shortcuts, and search engine.
- Edit `style.css` to tweak theme styles, colors, and layouts.
- Background GIFs/images are located in the `images/` folder.
